# Aje Bumi — V1 Homepage

Custom Next.js homepage scaffold for Aje Bumi.

## What is included
- Responsive homepage
- Header / navigation
- Editorial hero
- Brand story
- Collection preview placeholders
- Craftsmanship section placeholder
- Philosophy section
- Newsletter form UI
- Footer
- SEO metadata

## Important
No product prices, materials, inventory, or client claims have been invented. Replace placeholders with approved content and photography.

## Local development
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy
Import this repository into Vercel and deploy as a Next.js project.
